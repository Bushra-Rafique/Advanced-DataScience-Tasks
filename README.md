# Advanced-DataScience-Tasks
This repository contains five advanced, hands-on data science tasks completed as part of a professional internship. Each task focuses on a different domain—ranging from customer prediction and segmentation to time series forecasting, cost-sensitive risk modeling, and business intelligence.

## Task List Overview:

### Task 1: Term Deposit Subscription Prediction (Bank Marketing):
**Objective:** Predict whether a bank customer will subscribe to a term deposit following a marketing campaign.

**Key Concepts:**
- Classification models (Logistic Regression, Random Forest)
- Feature encoding
- Evaluation using F1-Score, ROC Curve, Confusion Matrix
- Explainable AI (SHAP / LIME)

**Skills Gained:**  
Customer behavior modeling, XAI, data preprocessing, evaluation metrics


### Task 2: Customer Segmentation Using Unsupervised Learning:
**Objective:** Group mall customers based on spending behavior and propose marketing strategies for each group.

**Key Concepts:**
- K-Means Clustering for segmentation
- Dimensionality reduction (PCA or t-SNE)
- EDA and strategy formulation

**Skills Gained:**  
Unsupervised learning, visualization, customer profiling, marketing strategy


### Task 3: Energy Consumption Time Series Forecasting:
**Objective:** Forecast household energy consumption using historical time-series data.

**Key Concepts:**
- Time series resampling and feature engineering
- ARIMA, Prophet, and XGBoost forecasting models
- MAE and RMSE evaluation

**Skills Gained:**  
Temporal modeling, forecasting techniques, time-based feature engineering, comparative model analysis


### Task 4: Loan Default Risk with Business Cost Optimization:
**Objective:** Predict loan default probability and adjust classification threshold based on cost-benefit trade-offs.

**Key Concepts:**
- Binary classification (Logistic Regression, CatBoost)
- Cost-based decision-making
- Threshold optimization
- Feature importance

**Skills Gained:**  
Risk modeling, business cost minimization, threshold tuning, financial impact analysis


### Task 5: Interactive Business Dashboard using Streamlit:
**Objective:** Build an interactive dashboard to monitor sales, profit, and customer KPIs from the Global Superstore dataset.

**Key Features:**
- Dynamic filters (Region, Category, Sub-Category)
- KPIs: Total Sales, Profit, Top 5 Customers
- Visualizations using charts in Streamlit

**Skills Gained:**  
Business Intelligence, interactive dashboarding, data storytelling, user-focused analytics


## Technologies & Libraries Used:

- **Python** (pandas, numpy, matplotlib, seaborn)
- **scikit-learn**, **CatBoost**, **XGBoost**
- **Statsmodels**, **Prophet** (for time series)
- **SHAP**, **LIME** (for explainability)
- **Streamlit** (for dashboards)
